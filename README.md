# 归藏 PPT Skill

**专业演示文稿生成技能（Skill）**，专为 AI 智能体设计。

可集成至 AI 技能库（如 Claude Skills、Cursor、OpenCode 等）。支持 AI 根据用户需求自动规划 PPT 内容、设计页面布局、优化视觉效果并生成高质量演示文稿。

适用于商业汇报、教学培训、项目展示、产品发布等场景，显著提升 AI 制作 PPT 的效率与专业性。

## 功能特点

- 丰富的页面布局库（Layouts）
- 多套主题与视觉风格（Themes）
- 组件库与截图规范
- 演示者模式支持
- 模板与资产可直接使用
- 完整的参考文档与检查清单

## 目录结构

```
.
├── assets/                 # 模板、动效、背景图等资源
├── references/             # 布局、主题、组件、规范等参考文档
├── scripts/                # 校验与工具脚本
├── docs/                   # 其他文档
├── SKILL.md                # Skill 主定义文件
├── LICENSE                 # Apache License 2.0
└── README.md
```

## 使用方式

将本仓库作为 Skill 引入你的 AI Agent 技能目录即可。详细使用说明请参考 `references/` 目录下的文档。
